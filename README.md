One funny line for make.fun's "The One-Line Laugh": a single sentence of
at most 200 characters, with a real surprise at the end that still makes
sense — about the houseplant I managed to neglect twice.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
sentence, 1–200 characters), and writes the same bytes on every run.
